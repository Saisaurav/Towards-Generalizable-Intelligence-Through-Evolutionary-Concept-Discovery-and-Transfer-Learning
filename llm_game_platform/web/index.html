A testbed for agents that learn tasks, and carry ideas from one to the next.

Frameforge is a developer tool and a research prototype. You describe a game or task, an LLM writes the environment as Python, and a learner trains from scratch to solve it. Any reusable ideas it discovers are saved, so later tasks can try them as extra inputs.

  1. Describe the task

    Write a game or task in plain language, or load a built-in such as Chess, Connect 4, Snake, Pong or Tic-Tac-Toe. The environment is generated as readable Python that you can edit.

  2. Validate it in a sandbox

    Each environment runs in an isolated process and is checked for legal actions, finite rewards, deterministic replay and a reward that separates good play from random play. Failures go back to the model to repair.

  3. Train an agent

    A C++ learner evolves network topology with NEAT and tunes the policy with PPO. Follow fitness per generation and inspect every genome in the population.

  4. Reuse concepts

    Genetic programming searches for small formulas over state and action that predict good moves. Kept in the concept bank, they are offered as inputs to the next task's fresh learner. Weights and network structure never carry over.

Made for developers

Environments are plain Python

A class with reset, observe, legal_actions, step and render. Edit the generated source in Agent Arena and it is validated again before you train.

Training runs locally

The learner is a C++ program behind the platform's HTTP API. Per-generation genome snapshots are saved next to each environment.

Take the policy with you

Trained robot policies are plain JSON, and the repository includes ROS 2 adapter examples for running one against a compatible Gazebo setup.

Where the research stands

Transfer between tasks is the open question here, not a result. In the experiments so far, concepts found on one game have not measurably improved learning on another. The gains we measured came from the lookahead features we supplied, not from discovery.

Runs are preliminary (single core, ten seeds), and the Robot Lab numbers come from simulated stand-ins for the TurtleBot and arm tasks, not from Gazebo or hardware.
